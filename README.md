# sekai-client
An unofficial API client for `project sekai`

It's recommended to create a `account.yaml` file with following content:

```yaml
userId: ~
signature: ~
credential: ~
GitHubToken: [your personal access token]
```

Generate your `Personal Access Token` here: https://github.com/settings/tokens. Enable `public_repo` is enough.

Also DONT forget to clone `[sekai-master-db-diff](https://github.com/Sekai-World/sekai-master-db-diff)`.
